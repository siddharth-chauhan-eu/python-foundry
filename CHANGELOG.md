# Changelog

This file records the notable changes in each release of the repository. The format follows
[Keep a Changelog](https://keepachangelog.com/). The rules for entries are in the
[Changelog](CONTRIBUTING.md#changelog) section of the contributing guidelines.

## [Unreleased]

### Added

- Zenodo DOI badge in the README and the concept DOI in the citation metadata.
- Source sections that name the courses behind the Python Fundamentals and Data Jobs Analysis
  content.
- Developer Certificate of Origin sign-off for commits (decision 0006).
- Rules for changelog entries in the contributing guidelines.
- A section on contributions other than code in the contributing guidelines.

### Changed

- The code of conduct lists a personal address for conduct reports.
- The security policy scopes dependency reports, sets a default 90-day disclosure period, makes
  credit consent-based, and lists an email address as a fallback for reports.
- The citation metadata lists keywords and a shorter citation message.
- The decision record guidelines define which decisions need a record and when to write it.

### Fixed

- Effective dates in decisions 0002 and 0003.
- A time reference in the context of decision 0005.
- A statement about the squash commit subject in the contributing guidelines.

## [0.1.0] - 2026-10-31

### Added

- First release of the repository.
- Python Fundamentals: exercises and a command-line dataset summary project.
- Data Analytics: exercises, notebooks, and a job-market analysis project.
- Locked project environment and a verification script that runs locally and in continuous
  integration.
- Licensing map, third-party notices, citation metadata, contributing guide, code of conduct,
  security policy, and decision records.
