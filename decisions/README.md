# Decisions

This directory records decisions about this repository that are hard to reverse or that a reader may
question. Each decision is an architecture decision record (ADR). The file name follows the pattern
`NNNN-short-title.md`. Numbers are never reused.

Each record has a status, a date, and three sections: Context, Decision, and Consequences. A status
is `Proposed` or `Accepted`. To change a decision, add a new record. Mark the old record as
superseded and link to the new one.

The structure of these records is adapted from the ADR practice described by Michael Nygard.
